05 / GET STARTED

把 Deernova 带进项目

将完整设计规范交给你仓库里的 AI，沿用项目现有的技术栈和组件。

安装到指定仓库

只添加设计 skill，不修改应用代码或依赖。

npx @deernova/style@latest install --repo ./your-project

也可以进入目标仓库，直接运行 npx @deernova/style@latest install。

让 AI 参考规范

在目标仓库中提出需求：

参考 deernova-style skill，
为这个项目实现设置页，保留现有技术栈。

更新已有 skill：

npx @deernova/style@latest update --repo ./your-project

默认安装到目标仓库的 .agents/skills/deernova-style。Claude Code 可追加 --agent claude。网页中的组件与 token 是设计参考；使用 skill 不需要安装组件库。
