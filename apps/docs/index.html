05 / GET STARTED

把 Deernova 带进项目

同一版本的规范、资源与模板，一起交到开发者和 AI 手中。

安装设计 skill

发布到 npm 后，在项目根目录执行：

npx @deernova/style@latest install

更新：npx @deernova/style@latest update
检查：npx @deernova/style doctor

使用样式与模板

npm i @deernova/tokens @deernova/ui
npx @deernova/style init ./my-site

CSS 入口：

@import '@deernova/tokens/tokens.css';
@import '@deernova/ui/components.css';

本地开发：npm install → npm run dev。未发布前可运行 node packages/style/bin/cli.mjs install。网站模板为静态 HTML，不绑定前端框架。
