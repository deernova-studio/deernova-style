# 首页改用生成的完整逐帧奔跑

用户确认以新的姿态图为准，并授权用内置 imagegen 补足帧数，在 `codex/refine-homepage-deer` 继续实现。

## 实现

- 生成 24 张完整动物姿态，按收腿与后腿落地、蹬伸腾空、前腿承重、离地回收分成四张 3×2 图集。
- 每张姿态完整绘制，仅整体缩放、平移以对齐躯干与落脚高度。不再拆分头颈、躯干和四肢，也不使用旧图的骨骼变形。
- 图集保留 imagegen 的透明通道；加载时裁切每格并转换灰度，继续使用原有网点和字符输出。
- 一个周期约 0.83 秒，24 个独立姿态。使用活动时钟选帧，场景循环、暂停恢复和固定时刻共用同一时钟。图片准备好后再开始播放。
- 保留草原、森林、星空、主题切换、减少动态效果和顶部导航。

## 验证

- 检查所有图集的透明背景、四肢与边缘完整性，逐帧核对连续动作及周期接缝。
- 测试帧选择、周期边界、场景时钟衔接、素材裁切区域，以及现有构建、规范和安装器检查。
- 在浏览器查看原始灰度和最终网点动画，检查桌面、手机、主题、固定帧和加载完成后的重绘。

素材、完整提示词与实际验证结果分别记在 `reviews/reference/milu-generated-cycle.md` 和 `reviews/verification.md`。
