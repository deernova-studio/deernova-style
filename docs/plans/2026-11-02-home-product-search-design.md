# 首页顶部产品入口

沿用首页的黑白灰、衬线字标和玻璃顶栏。按用户澄清，最外层胶囊顶栏本身就是入口，点击字标或空白区域展开产品菜单，不再增加内部输入框。菜单与顶栏同宽并左右对齐，内容保持紧凑。桌面增大两侧留白并限制总宽；右侧仅保留设计规范、GitHub、外观三个独立图标。图标有悬停说明和无障碍名称。桌面和手机均为单行。

入口使用原生按钮，右侧图标是同级控件，避免交互嵌套。点击或 Enter/空格切换展开；方向键进入和切换产品，Home/End 到首尾，Esc 收起并返回入口；焦点移出或点击外部收起。条目是可正常 Tab 聚焦和打开的原生链接，当前只放已有的 Deernova Style，后续添加同结构条目即可扩展。

复用现有字体和颜色变量。下拉与顶栏共用 glass-fill、glass-stroke 和相同的背景模糊，浅深主题一起切换；降低透明度时两者一起改用 surface-raised。顶栏玻璃放到独立伪元素上，避免它成为下拉背景模糊的边界。展开状态不额外给整条顶栏叠色。

产品列表仅展示图标、产品名与导航箭头，去掉可见分组标题和描述。Deernova Style 使用用户最终确认的 ui 图标：u 两侧形成鹿角，i 对齐四芒星，竖线底部小圆角。原 PNG 不改，SVG 将亮度转换成遮罩以跟随浅深色主题。

按仓库 deernova-style 的 Web 密度与 token 落地：桌面名称 14px / 20px、图标 20px、行高至少 32px；`pointer: coarse` 下名称 17px / 23px、图标 24px、点击区域至少 44px。外层圆角 8px、内边距 4px、行圆角 4px，间距沿用 4px 网格。文字使用 rem 并允许换行，不截断长产品名。
