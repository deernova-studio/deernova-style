# Claude Code desktop 实测对照

> **状态：已按讨论落地（2026-11-04）。** 骨架、尺寸、线条、字体和组件形态对标 Claude 桌面端；保留 Deernova 的黑白灰、克制风格和文案规则；SwiftUI 端保留系统 Liquid Glass，只有 Web 应用不用玻璃；衬线只留给大标题、官网和文章类长文。密度从四档合并为三档（桌面、触控、舒展），macOS 的系统控件保持系统尺寸，自己画的内容区用桌面档。补充实测：Web 对话栏 752 宽时内容宽 = 栏宽 − 88（665），尚未触到最大宽度；主按钮 28 高、深色下白底黑字，次按钮 28 高、灰底无描边。仍未实测：浅色主题与阴影、菜单、弹窗、设置页、表单输入框、代码块。

对象：Claude 桌面端的 Code 标签页（本机当前窗口，深色主题，窗口 1329 × 893pt，Retina 2 倍截图）。方法：只截取 Claude 窗口，按像素扫描颜色边界量尺寸、拟合圆角，用字形高度反推字号（SF Pro 大写字母高 ≈ 0.705em）。颜色不在对标范围内。

单位都是 pt（等于 CSS px）。量出的值误差约 ±0.5pt；圆角是拟合值，实际多半是相邻的整数（例如 13.5 → 14）。

## 结论

没有对标上，而且差在“骨架”而不只是数值：

1. **没有玻璃。** Claude Code desktop 的侧边栏、顶栏、输入区都是不透明的平面，用 1pt 的线分隔。Deernova 的第一条核心规则是“操作浮在玻璃上”。
2. **没有衬线。** AI 回答、标题、会话名全部是系统无衬线（SF Pro），代码是 SF Mono。Deernova 规定 AI 回答和标题用衬线。
3. **线更粗。** 所有分隔线和描边都是 1pt（2 个物理像素），Deernova 用 0.5pt 的发丝线。
4. **更大、更松。** 正文 15/24，比 Deernova 的 macOS 档（13/18）大两号，也比 Web 应用档（14/20）大一号；侧边栏 287 宽；卡片、气泡、输入框的圆角是 12–14，Deernova 是 8–12。

一致的地方：按钮和图标按钮 28 高、圆角 6；侧边栏行 32 高；块与块之间 16；用户消息放在凹下去的气泡里；工具调用是灰色的一行文字加展开箭头。

## 尺寸和线条以外的差异

**规则层面**

- **玻璃**：Claude 没有，全部是不透明平面加 1pt 线。
- **衬线**：Claude 没有，全部无衬线。
- **原生优先**：Claude 桌面端是跨平台的 Web 技术界面，分段切换、按钮、侧边栏都是自己画的，Mac 和 Windows 长得一样；Deernova 的 macOS / iOS 场景要求直接用 SwiftUI 系统控件（`NavigationSplitView`、系统玻璃工具栏）。
- **字重**：Claude 很少用粗体：分组标题、会话名、顶栏标题、正文都是常规字重，层级靠字号和灰度；Deernova 的分组标题、区块标题、标签用 500–600。

**层次关系**（不是色值，是谁比谁亮）

- 深色下 Claude 的侧边栏比内容区**亮**一层（`#1f1f1f` 对 `#191919`），Deernova 的侧边栏用 `surface-sunken`，比内容区**暗**。
- Claude 侧边栏的选中项是明显的实色块，Deernova 的 `fill-selected` 是很淡的半透明。

**Claude 有、Deernova 没有或不一样的界面模式**

- **任务清单卡片**：描边卡片里一行一个任务，左边是状态圈（转圈、虚线圈、完成），每行 28。Deernova 只有执行步骤行。
- **工具调用摘要行**：一行灰字汇总「已运行 1 个命令，已读取 screen.png」，加展开箭头，可带缩略图；Deernova 的执行步骤是一步一行，带动作名、等宽摘要和耗时。
- **运行中状态**：动画圆点 + 「正在运行 命令 42 秒」。
- **输入区结构**：左边是加号，右边是停止（方块）和语音；模型、思考强度、权限模式和上下文用量放在输入框**下方**一行；额度提示条贴在输入框上方。Deernova 的 Composer 把模式选择和状态放在框内工具条里。
- **多栏布局**：对话右侧可以并排打开终端、预览等面板，面板有自己的标签头；Deernova 没有侧面板和标签头的模式。
- **顶栏**：会话标题带下拉箭头，右侧是一排 28 的图标按钮（任务、终端、改动、浏览器、设备、文件、更多）。
- **侧边栏结构**：顶部是带图标的全局入口（新建、搜索、Artifacts、定时任务、自定义、更多），下面按项目分组、组标题可折叠、会话名不带图标，底部是头像、账号和设置齿轮。Deernova 的侧边栏是“分组标题 + 带图标的项 + 右侧计数”。
- **窗口顶部**：红绿灯和侧边栏开关、前进后退、Code / 对话切换放在侧边栏顶部，不用系统工具栏。

## 没有量到的

- 浅色主题，以及卡片、输入区在浅色下的阴影（深色下看不出阴影）。
- 对话栏的最大宽度：这次窗口偏窄（对话栏 614），内容宽约 528–550，看不出是最大宽度还是左右留白。
- 下拉菜单、弹窗、设置页、输入框（表单）的尺寸：截图时没有打开。
- 字体是否为系统 SF Pro 还是外观相近的品牌字体：从字形看是 SF Pro，没有读取应用代码确认。
- 动效（展开、切换、转圈的时长和缓动）、代码块、Markdown 里的列表、表格、引用和链接样式。
- Windows 上的样子。

## 如果要对标，需要改什么

尺寸（主要改常规档，紧凑档是否跟随要你定）：

- `type-body` 15 / 24，`type-prose` 15 / 24，`type-headline` 15 半粗，`type-callout` 14，`type-caption` 13 常规字重。
- `sidebar-width` 288，`row-height` 32（不变），行间隔 2，`row-padding-x` 8。
- `card-radius` 12，`composer-radius` 14，横幅圆角 10，用户气泡内边距 12 × 16。
- `stroke-hairline` 改为 1px（或者分隔线统一用 `stroke-control`）。
- 新增 `toolbar-height` 44。

规则：

- 核心规则 1 从“纸面与玻璃分层”改成“不透明平面 + 1pt 分隔线”，玻璃只保留给 iOS / iPadOS 的系统导航。
- 核心规则 4 从“衬线说话、无衬线做事”改成全部无衬线；衬线只留给官网与文档的大标题，或者完全去掉。
