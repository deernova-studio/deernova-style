# 在当前完整鹿形上恢复奔跑

> 已撤回：按用户要求恢复修改前的走路版。以下是历史实验记录，不代表当前首页或当前源码。

保留已统一的整腿驱动和连续皮肤。走路参数保存在 `art/milu/gaits/walk.json`，奔跑使用单独的 `run.json`，可重烘焙对照。

选择前腿接地承重、后腿跟进蹬伸、腾空再接前腿的节奏。四肢共用周期和地面速度；头颈、躯干、四肢一起经过同一个身体变换。先在世界坐标安排蹄子，再换算到身体坐标求解固定骨长，避免身体上升时支撑脚离地。

单纯加速走路无法产生腾空和成对蹬伸；完全重画图集则容易丢失已稳定的外形。本次先沿用当前皮肤与骨架，采用幅度适中的奔跑，正常速度和慢放均检查。

验证支撑期贴地、腾空阶段、关节可达性、骨长、表面不翻折、周期首尾与共享头身运动。最后烘焙到首页，保留 60fps 调度及点击上色。数值通过仍需实际画面对比。

## 后蹬与前后接力修正

反馈是原地跳感、后蹬短。保持已经接受的整个身体变换与步频，后蹄的着地轨迹向后移，步幅由 76 增为 94；地面速度由同一轨迹计算。前后腿的落脚间隔略作错开，抬蹄与蹄子卷起共用一个较早到达高点的连续曲线，以便前腿在腾空之前开始伸展。回归检查完整身体轨迹指纹、支撑末端后蹄相对髋部的位置、前腿伸展时机，并检查成品画面。
