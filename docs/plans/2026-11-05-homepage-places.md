# 首页增加四个场景

用户希望增加摩天大楼城市、工厂、海边和稻田。延续现有黑白网点、分层移动和点击上色，使用当前已确认的鹿形和行走素材。

## 画面

- 城市：赛博朋克夜景，远近三层暗色楼群、错层塔顶、霓虹招牌、亮窗和湿地倒影。黑白模式以明暗呈现，点击鹿上色后呈现青色与紫红色灯带。
- 工厂：锯齿屋顶、不同高度的烟囱、缓慢飘散的蒸汽、窗列和外露管道，前景为厂区地面。
- 海边：海平线、远岬、小帆船、白色海鸥和分层浪纹，鹿沿干燥沙滩前行。
- 稻田：远丘、分层水田与田埂、随风摆动并低垂的稻穗，鹿走在平整田埂上。

继续由 Canvas 绘制共享的场景几何。这样黑白层与上色层有完全一致的位置和运动；静态背景图需要额外拆层，独立生成图也容易偏离原有轮廓风格。

## 接入

顺序为草地 → 稻田 → 城市 → 工厂 → 海边 → 森林 → 雪山 → 夜景 → 沙漠。每处 8.4 秒，最后 1.6 秒沿用横向切换，完整循环 75.6 秒。场景切换不改变鹿的活动时钟、步频和地面速度。

`scenery-places.js` 使用 `scenery.js` 的色调、分层滚动、地形和植物绘制方法。每帧读取同一个活动时钟，固定帧保持确定性；仅在上色可见时绘制彩色层。城市点击空处亮起扫动灯光，海边出现白色海鸥，工厂出现蒸汽，稻田触发阵风。原有键盘上色保持可用。减弱动态模式仍停留在夜景，时间由场景顺序计算。

## 验证

检查九个切换边界、点击分流、上色期间鹿姿态连续、减弱动态和键盘。导出桌面与手机的黑白／彩色／深色预览，并在实际浏览器测量四个新场景的绘制耗时。无需重新生成或烘焙鹿的图集。
