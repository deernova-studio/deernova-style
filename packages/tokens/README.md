# @deernova/tokens

Deernova semantic design tokens. Import `@deernova/tokens/tokens.css` or consume `@deernova/tokens/tokens.json`. Light/dark modes follow the system by default; set `data-theme="light"` or `data-theme="dark"` on the root to override it.

Generated from the deernova-style monorepo's `design/tokens.json`. Keep versions aligned with `@deernova/ui` and `@deernova/style`. Use `accent` with `on-accent`; reserve status colors for meaningful states.
