# @deernova/ui

Framework-neutral Deernova component CSS and 18 HTML previews.

```css
@import '@deernova/tokens/tokens.css';
@import '@deernova/ui/components.css';
```

Classes use the `dn-` prefix. `components/<Name>/preview.html` demonstrates markup and visual states; the adjacent README explains usage and native SwiftUI equivalents. Previews include a local token stylesheet so they can also be served directly.

This package contains styles and examples, not application behavior or compiled React/SwiftUI components. Integrate accessible keyboard, form and dialog behavior in your framework. Match the tokens package version.
