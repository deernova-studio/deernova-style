# 点击上色验收

点击鹿的实际轮廓：颜色从点击位置扩散，0.95 秒铺满，停留 3 秒，1.2 秒淡回黑白。再次点击延长停留，淡出中再次点击平滑恢复；不暂停或改变步态。腿间与鹿角间的空白继续触发各场景原有特效。

五个场景采用各自的插画色板，保留网点与字符；顶栏继续使用原有设计变量。画布支持键盘和辅助技术激活。减弱动态效果／固定帧模式直接切换颜色，不恢复动画。

- [完整效果，60fps](click-color-60fps.mp4)：使用首页实际绘制代码导出；第 1 秒点击鹿，第 2.5 秒点击右侧天空，最后恢复黑白。视频只包含画布。
