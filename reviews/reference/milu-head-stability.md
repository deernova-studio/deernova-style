# 独立头部实验（已撤回）

2026-11-03，分支 `codex/refine-homepage-deer`。

已撤回：用户反馈身体运动时头部不跟随，头颈与躯干割裂。当前首页恢复完整动物姿态；下方是失败实验的实现与验证记录，不代表当前实现。数值上的头部稳定没有带来自然的整体运动。

## 原因与处理

逐格查看后，六张生成图集中的头脸、鹿角比例和角度并不一致；躯干对齐后，整帧混合仍会让头部缩放、换形。继续补整帧不能保证消除这种差异。

- 复用现有 `milu-cycle-push.png` 第 2 格（源编号 37）的头部和鹿角；不新增或重绘图像资源。
- `head.js` 定义参考眼点、颈部渐变遮罩和小幅周期运动。头部不再参与两个不同造型之间的混合，每次绘制只使用同一张不透明缓存；横向位置和大小固定，上下起伏在 200px 场景单位下每个 60Hz 步长小于 1px。
- `stag.js` 在加载时通过颈部渐变衔接参考头部与原躯干，遮罩在下肢和蹄部区域严格为零。躯干、腿、姿态顺序、跳跃轨迹及 60fps 调度沿用上一轮。
- 头部参考图加载失败时，保留未裁去头部的完整姿态；重试成功后再切换到共享头部。已处理的帧不会重复应用遮罩。
- 共享头部的边界加入点击区域和横向布局范围。

## 验证

- `npm test`：57 项通过，网站和 skill 构建通过；`git diff --check` 通过。
- 回归覆盖头部循环接缝、运动幅度、缓存复用、混合时保持不透明、腿部像素不被遮罩、缺少参考图时的降级与重试。
- 实际 Canvas 绘制比较 200 个奔跑／跳跃状态的下肢区域：95,095,200 个通道值中 1,033 个有差异，最大 alpha 差为 1/255，预乘颜色差小于 2/255，属画布取整导致的边缘舍入；下肢几何和轨迹未改变。没有声称逐字节完全一致。
- 八种视口各 2002 个状态的身体及共享头部边界扫描通过，320px 视口仍保留 12px 横向余量。
- 已检查灰度慢放和实际首页。[前后对比视频](../head-stability.mp4) 由实际绘制代码离线输出，左为完整姿态、右为已撤回实验，奔跑正常速度、跳跃半速，不是浏览器帧率录制。

颈部采用羽化衔接，躯干和四肢的生成细节差异仍可能在帧间混合中产生重影。没有重新测量真实设备上的逐帧耗时。
