## 动作改变

四条腿共用每秒 1.2 个完整循环。前腿先后落地承重，后腿跟进蹬伸，随后进入约四分之一个秒的腾空，再由前腿接地。每条腿仍各完成一次收回、前摆与后蹬，不再分别设置前后腿的频率。

头、脖子、躯干和四肢使用同一个身体变换，整体小幅起伏与俯仰。蹄子先在地面坐标安排，再逆向换算到身体坐标求解关节，避免身体上升时把腿拉长、把支撑脚抬离地面。腿部沿用连续表面，未重新引入身体与腿的水平分割。

检查了接地、收腿、后蹬与腾空阶段的成品帧，以及上色后的交叠。它仍是二维插画骨架，强弯曲下的轮廓有插画式棱角，未模拟深度旋转或肌肉形变；正常速度是否达到预期仍以观看体验为准。

## 验证

- 23 项 Python 测试通过：支撑脚贴地及速度、腾空、固定骨长、接点和循环首尾速度连续、640 个时刻无皮肤三角形翻折。
- 对实际发布的全部 160 帧，将头、颈、背部和躯干核心的像素与原图经过同一次刚性变换后的结果逐一比较，未单独固定头或替换像素基线。
- `npm test` 的构建与 63 项测试通过，覆盖 60fps 调度、素材、帧间取值和交互。
- 独立 Chrome 在 1280×800、设备像素比 1 下测得黑白约 59.7fps，上色稳定区间约 60.0fps；绘制中位耗时约 7.3 / 7.4ms。上色测量在截图和像素回读之前进行，未关闭 GPU，也未同时运行视频导出。结果不是所有设备的性能保证。
- 浏览器点击鹿上色、自动褪色、键盘激活及减弱动态效果检查通过，没有运行时异常。

预览 MP4 的 60fps 是导出采样率；上述浏览器记录单独验证实际播放性能。
