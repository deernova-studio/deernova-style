# 后蹬与前后腿衔接

> 已撤回：按用户要求恢复修改前的走路版。以下是历史实验记录，不代表当前首页或当前源码。

反馈：奔跑仍像原地跳，后腿缺少明显的向后蹬伸；调整腿部时不能再次打乱头、脖子和身体的共同运动。

## 这次修改

- 步幅从 76 增至 94 个工作像素，后腿轨迹中心后移 26px。后蹄离地前位于髋部后方约 73–78px，原来约 38–43px；后腿先撑地伸展再收回，不再在髋部附近提前折起。
- 四次落脚调整为相位 0、0.13、0.26、0.4，四肢仍共享每秒 1.2 个循环。地面速度随统一支撑轨迹从约 1.69 调整到 2.09 场景单位/秒。
- 摆腿高点从离地阶段中点提前至 3/8，蹄子卷起与抬腿使用同一条平滑曲线。前腿在腾空前开始伸展，避免飞行阶段前后腿同时长时间蜷曲；抬蹄幅度适当减小。
- 身体变换、步频、腾空时段、头颈与躯干连接都保持上一版。`run-body-lock.json` 保存修改前的完整身体轨迹指纹；测试要求全部 160 个相位一致。

## 验证

26 项 Python 测试与 63 项 Node 测试通过。新增检查后蹄离地前相对髋部的位置、后蹬时下腿向后伸展、前腿提前伸展，以及完整头身轨迹保持不变；保留固定骨长、循环首尾与接地处的连续性、皮肤不翻折和成品头颈像素检查。

另外将修改前后图集的全部 160 帧注册到相同坐标，对头、颈、背部和躯干核心区域逐像素比较，变化像素为 0。肩、髋和下腹是腿部转动所需的变形区域，不在该比较范围内。

实际 Chrome 在 1280×800、设备像素比 1 下，黑白约 60.0fps，上色约 60.0fps；绘制中位耗时约 7.0 / 7.3ms。点击上色、自动褪色、键盘与减弱动态效果通过，没有运行时异常。见 [浏览器记录](browser-check.json)。离线视频的 60fps 采样率与此性能检查分别记录。
