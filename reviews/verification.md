# 当前验收状态

更新于 2026-11-02。本轮在 `codex/refine-homepage-deer` 按用户确认图重做首页动画。此前版本见 [历史记录](history.md)。

## 当前实现

- 使用 [确认的插画](reference/milu-running.png) 的轮廓和明暗，内置 imagegen 生成的 [透明素材](../apps/website/assets/milu-running.png) 在加载时转换为灰度并分层。素材处理提示词、设计和模块分工见 [设计记录](../docs/plans/2026-11-02-reference-gallop-design.md)。
- 四肢按固定骨长求解，每条腿经历落地、支撑、蹬离、折叠和前摆；着地蹄子的速度与地面一致。身体小幅起伏，头颈轻微反向补偿。
- 30 秒场景循环中有 45 个完整步态周期。星空山脊在落脚范围内保持平坦，向两侧接回起伏地形。
- 手机网格为 3px，桌面为 3–5px。草原、森林、星空和字符转场沿用现有场景，顶部导航保持上一轮布局。
- 官网素材单独构建，规范源文件和 npm 安装器没有改动。
