# 头、颈、躯干共同运动 · 2026-11-04

旧版分别平滑头部、混合躯干，再按躯干移动整张图。躯干变稳后，头相对身体仍前后摆动；上一轮的平移补偿还放大了首页头部的绝对摆幅。

本次移除 `bake.py` 中独立的头部及鹿角拟合。`body.py` 使用同一张连在一起的头、颈、躯干绘画，共享随步态变化的起伏与俯仰，保持三者之间的比例。腿根承接相同运动，蹄子附近的位移衰减到零。没有单独固定头部，也没有在运行时额外叠加一套头部动画。`motion.py` 对 `bodyMotion` 素材保留共同运动，不再追加躯干横向校正。

## 效果

- [同速对比](head-body-comparison.mp4)：左旧右新，直接运行首页的 `createStagRenderer` / `createGait`，60fps、8 秒。
- [首页效果](homepage-60fps.mp4)：实际网点绘制，包含行走、停下与重新起步，60fps、8 秒。
- [桌面](homepage.png)、[停下](paused.png)、[手机](mobile.png)。

以上通过原生 Canvas 离线运行项目绘制模块，未包含导航 DOM，不能用于宣称浏览器运行性能。

## 保留的限制

腿部仍由四个关键姿态补间，交叠位置仍可能出现局部形变或重影。上半身暂时采用统一的小幅运动，未添加耳朵等次级动作。此次预览来自实际首页素材；此前独立生成的 60 张彩色图仍保留为历史实验，未将其组间姿态跳变带入首页。
