## 制作方式

每格按固定画布裁切，不依照随腿变化的外接矩形单独缩放，不分别固定头部或拉伸腿。16 格按阅读顺序组成 1.6 秒循环，末尾追加首格以包含循环接缝。

使用 [RIFE ncnn 的官方工具](https://github.com/nihui/rife-ncnn-vulkan) 20221029 版本和 v4.6 模型做整帧视频补间。离线生成每轮 192 个样本：正常速度隔帧取样，半速逐帧取样，两段输出均为 60fps。FFmpeg 编码为 H.264。它们是视频补间样本，不是 192 张人工校验过的原始姿态。

工具和模型只放在临时工作目录，没有加入网站依赖。制作脚本为 render_preview.py，依赖 Pillow、FFmpeg 和指定的 RIFE 可执行文件、模型目录：

```sh
python render_preview.py --rife /path/to/rife-ncnn-vulkan --model /path/to/rife-v4.6 --font /path/to/chinese-font.ttf
```
