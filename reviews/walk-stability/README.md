# 横向漂移与落脚颗粒修正 · 2026-11-04

## 发现的问题

60 张图的固定网格切片没有校正格内鹿的位置。每五格存在逐渐向左偏、下一行重置的规律，导致前后跳动。首页现有的 80 帧图集也有横向漂移。雪地、沙地和夜景的蹄子效果原来持续出现在固定偏移处，并未跟随接地动作，站定时仍会喷出。

## 本次修改

- 以胸腹部图像测量整只鹿的横向偏移。只进行整帧平移，不改变纵向位置、比例、角度或头身关系。原始图像文件保持不变。
- 首页使用测量后的偏移绘制完整图像，混合区域、手机边界及点击区域同步考虑偏移。
- 蹄子颗粒由图集里实际可见的接地时刻触发。每次仅 3–4 个小颗粒，最高约 0.02 场景单位，持续 0.26–0.32 秒；落点随地面滚动。草地和夜景取消蹄子烟团、星形喷射。

## 对比与复现

- `walk-comparison.mp4`：左侧原始 60 图，右侧校正横向位置，60fps、6 秒。
- `walk-stabilized.mp4`：校正版本单独播放。没有光流补帧、姿态插值或交叉淡化，保留原 60 张姿态。
- `assemble.py`：读取 `../walk-60/frames` 并复现以上两个视频；使用 `art/milu/requirements.txt` 中的依赖及 FFmpeg。
- `homepage-dust-comparison.mp4`：左侧修改前、右侧修改后。项目实际绘制模块在原生 Canvas 中离线运行，行走后点击停步；不是浏览器性能录像。
- `homepage-walking.png` / `homepage-stopped.png`：沙地颗粒对比。
- `homepage-halftone-*.png`：修改后的网页网点绘制结果，未包含导航 DOM。
