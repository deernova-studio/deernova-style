# 无障碍

## 对比度

- 每个文字 token 在它说明里注明的纸面上不低于 4.5:1，两套主题都验算过（`npm test` 会检查）。
- 如果必须靠描边识别控件，该边界不低于 3:1。普通输入框采用标签、底色和输入内容共同标识，不强制添加深色边框。
- 不要因为用了 token 就假定一定达标，要看它放在哪种纸面上。

## 点击区域

可见尺寸和点击区域是两回事：可见尺寸按组件的高度 token，点击区域不小于 `hit-min`（桌面档 24，触控档 44）。差的部分用透明的命中区补足，**不加大可见的控件**。

- **Web**：给控件 `position: relative`，用 `::before` 伪元素把命中区撑到 `max(100%, var(--hit-min))`。不要在有背景的元素上加 padding：CSS 的 padding 在背景里面，会把可见的按钮一起撑大。写法见 [按钮](../components/button.md)。
- **SwiftUI**：在 `.buttonStyle()` 之后加 `.padding()`（这时 padding 在背景外面，是透明的），再加 `.contentShape(.rect)`。
- 相邻的两个控件，命中区不要重叠。

## 字号与缩放

- iOS 全面支持动态字体，在最大字号下也不截断文字：允许换行，横排放不下就改成竖排（`ViewThatFits`）。
- Web 在浏览器缩放到 200% 时，长中文、长英文和空数据都不溢出、不重叠。

## 其他

- 只有图标的按钮必须有无障碍标签；用鼠标或触控板时出现的 [tooltip](../components/tooltip.md) 在键盘聚焦时也要显示，能用 Esc 关闭，指针移上去不消失。
- 只靠颜色传达的信息，一律补上图标或文字。
- 键盘位置要看得见：用键盘聚焦时，按钮、链接、卡片、开关这类控件出现 2px 的 `focus-ring` 焦点环，鼠标点击时不出现；菜单和建议列表用高亮底；输入框聚焦时底色变白（深色主题亮一档）并带一层柔和阴影，同时滚动到可见位置。`:focus-visible` 也会匹配鼠标点入的输入框，所以输入框不用焦点环。Tab 顺序合理，Esc 能关闭弹层。
- 开启「减弱动态效果」时只保留淡入淡出；开启「降低透明度」时玻璃换成实色纸面。
