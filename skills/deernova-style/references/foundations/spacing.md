# 间距

4pt 网格，整体偏紧凑。层次靠间距建立，不靠加更多的线和框。数值见 [设计变量](../tokens.md) 的「间距」。

## 刻度和语义间距

刻度 `space-1`（4）到 `space-16`（64）是固定值，日常布局基本只用 `space-1` 到 `space-4`。

更常用的是按密度取值的语义间距，写代码时优先用它们。内容区里段落、工具调用行、卡片之间统一 `space-4`（16）。

| Token | 用在哪里 |
| --- | --- |
| `gap-inline` | 同一行里图标和文字之间、按钮里图标和标签之间 |
| `gap-stack` | 同一组里相邻元素之间：表单项、卡片里的段落、并排的按钮 |
| `gap-group` | 组与组之间：设置分组、页面区块。至少是 `gap-stack` 的 2 倍 |
| `page-margin` | 页面和内容区的左右边距 |

组件内部的间距（卡片内边距、按钮左右内边距等）见各组件的尺寸表。

## 规则

- 组与组之间的间距至少是组内间距的 2 倍。
- 控件的高度由高度 token 决定（`button-height-*`、`field-height`、`row-height`），不用上下内边距去撑。上下内边距只用于多行内容：卡片、横幅、Composer。
- 同一行里的控件用同一个高度档位。
- 用 1px 线和少量留白分组；不要用大块空白，也不要每组都套一个框。

## 布局

分栏、内容宽度、对齐（包括垂直居中）、滚动和断点，见 [布局与对齐](layout.md)。

## 触控端比指针端大是有意的

手指比鼠标指针粗，触控端的控件和行高都更大（默认按钮 36 对比桌面的 28）。在 Mac 屏幕上看 iOS 设计图会比真机上大 20%–40%，判断大小时以真机为准。
