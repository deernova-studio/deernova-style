# 字体

全部使用系统字体，不打包字体文件。无衬线做界面，衬线只用来点题。

| 角色 | 西文 | 中文 | 用在哪里 |
| --- | --- | --- | --- |
| 无衬线 `--font-sans` | SF Pro | 苹方 | 所有界面文字：按钮、标签、列表、表单、标题栏、AI 回答、用户消息 |
| 等宽 `--font-mono` | SF Mono | 苹方 | 代码、命令、文件路径、需要对齐的数据 |
| 衬线 `--font-serif` | New York | 苹方 | 只用在页面大标题、空状态标题、官网与文档、文章类长文 |

Windows 和 Android 上会落到各自的系统字体，这是预期的，不要为此加载网络字体。

## 字号角色

字号按角色组织，不按平台。每个角色在三种密度下各有一组字号和行高，完整数值见 [设计变量](../tokens.md) 的「字号角色」。

| 角色 | 字族 | 用途 |
| --- | --- | --- |
| `display` | 衬线 600 | 空状态、引导页、页面的大标题，每屏最多一个 |
| `title` | 衬线 600 | 文章标题、弹窗标题 |
| `headline` | 无衬线 600 | 区块标题、卡片标题、横幅标题、列表行标题 |
| `body` | 无衬线 400 | 界面正文、AI 回答、用户消息、列表、表单。桌面档 15/24 |
| `prose` | 衬线 400 | 文章、文档这类长文阅读。AI 回答不用它 |
| `callout` | 无衬线 400 | 说明文字、弹窗正文、AI 输入框右下方的模型、权限和上下文用量 |
| `footnote` | 无衬线 400 | 侧边栏分组标题、分组列表的页头页脚、卡片摘要 |
| `caption` | 无衬线 400 | 时间戳、计数、标签 |
| `code` | 等宽 400 | 代码块、命令、文件路径 |

- Web：`font: var(--type-body)` 一次写全字重、字号、行高和字族；只要字号时用 `--type-body-size`。
- SwiftUI：`.font(.deernovaBody)`。macOS 上是固定字号（`.system(size: 15)`），只用在自己画的内容区；系统控件保持系统字号。iOS 上是文本样式（`.body`、`.headline`），动态字体会生效，不要写死 `size:`。
- 按钮、输入框、标签有自己的字号 token（`button-font-size-*`、`field-font-size`、`tag-font-size`），见组件说明。

## 字重

只用 400、500、600（`weight-regular`、`weight-medium`、`weight-semibold`），不用 700 以上。层次先靠字号和灰度，再考虑字重：

- 600：`display`、`title`、`headline`，以及 AI 回答里的加粗。
- 500：按钮、标签、表单标签。侧边栏的选中项靠底色区分，不加粗。
- 400：其余全部，包括侧边栏分组标题（`footnote` + `ink-tertiary`）、会话名、顶栏标题、说明、时间戳。

## 规则

- 界面文字行高约为字号的 1.4–1.6 倍；正文 15/24，中文读起来不挤。
- 只有 `display` 收紧字距（`--type-display-tracking`），其余保持默认。
- 需要上下对齐的数字（计数、价格、时间）用等宽数字：`font-variant-numeric: tabular-nums` 或 `.monospacedDigit()`。
- 想让中文标题也有衬线的气质，可以打包思源宋体（Source Han Serif，开源可商用）的子集，只用在官网大标题上。
- 界面紧凑不等于字小：最小的字是 12（`caption`）。

## 不要

- 给按钮、标签、表单、AI 回答用衬线。
- 用粗体做分组标题，或在一屏里堆很多粗体。
- 让按钮、输入框继承页面的行高。控件里的文字行高设为 1，高度交给 `height`。
- 在 iOS 上写死字号让动态字体失效。
