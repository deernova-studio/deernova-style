# 审查清单

用来检查一个界面是否符合 Deernova。按下面的顺序逐项看，只报告实际发现的问题。

## 检查项

- **层级**：内容在不透明的纸面上，操作在玻璃上；玻璃上没有段落和列表，没有玻璃叠玻璃；纸面层级按 `canvas` → `surface` → `surface-raised` 递进。
- **颜色**：只有黑白灰；`accent` 跟随 `ink`，主按钮文字用 `on-accent`（深色主题下是黑字）；彩色只出现在状态上，并且同时有图标或文字；没有写死的十六进制颜色。
- **对比度**：实际测量前景和背景的组合，正文不低于 4.5:1，输入框边框等有意义的控件边界不低于 3:1。不要因为用了 token 就假定一定达标，要看它放在哪种纸面上。
- **线条与阴影**：分组靠细线和间距；卡片没有阴影；阴影只出现在菜单、弹窗、浮动面板和 Composer 上。
- **字体**：标题和长文是衬线，按钮、标签、列表、表单是无衬线，代码是等宽；iOS 用文本样式，没有写死字号；对齐的数字用等宽数字。
- **尺寸与间距**：间距在 4pt 网格上；Mac 控件 24pt、列表行 26pt；iOS 点击区域至少 44pt，按钮尺寸按位置选（30 / 36 / 46）；嵌套圆角同心；阅读栏宽不超过 680。
- **交互**：一屏最多一个主按钮；按钮文字以动词开头；有悬停、按下、选中、禁用、加载、空、错误这些需要的状态；禁用和加载时布局不跳动；键盘焦点清楚。
- **动效**：动效说明因果；没有无目的的循环；减弱动态效果时只剩淡入淡出；切换内容时阅读位置不跳。
- **无障碍**：两套主题都看过；最大字号下不截断；只有图标的按钮有标签；降低透明度时玻璃变成实色。
- **文案**：用「你」；没有感叹号和 emoji；完成态用「已保存」；错误说明原因和解决办法；中文与英文、数字之间有半角空格。

## 怎么汇报

每个问题写清楚：严重程度（阻塞 / 明显 / 细节）、位置（文件和行号，或页面上的位置）、对用户的影响、具体怎么改。把亲眼确认的问题和推测的问题分开写。

审查不等于授权重做：只改被要求的范围，不顺手改动无关页面，也不提高项目的最低系统版本。
