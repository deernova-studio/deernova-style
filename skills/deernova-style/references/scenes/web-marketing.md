# 官网与文档

官网、产品介绍页、文档和规范页这类以阅读为主的页面，用**舒展**密度（`comfortable`）：字号和留白更大，控件只用于少量导航。仍然只用黑白灰、细线分组、衬线标题。

应用界面（后台、工具、编辑器）不要用这套尺寸，见 [Web 应用](web.md)。

## 启用

在 `<html>` 上设置 `data-density="comfortable"`，整页的字号、按钮、间距 token 都会换成舒展的值。只有某一块是阅读页面时（例如应用里嵌的帮助文档），把属性加在那一块的容器上。

## 版式

- 大标题用 `type-display`（衬线）。首屏标题可以再放大，用 `clamp()` 跟随视口，例如 `font-size: clamp(40px, 6vw, 88px)`，但每页只有一个。
- 正文 `type-body`，长文 `type-prose`，栏宽不超过 `content-max`。
- 章节之间 `gap-group`（48），首屏上下留白 `space-16`。
- 一页只用一套 12 栏网格，栏间距 `grid-gutter`；左右边距 `page-margin`，内容不超过 `wide-max`，两侧留白。见 [布局与对齐](../foundations/layout.md)。

## 控件

- 按钮是胶囊形（`button-radius`），大号 44 高，首屏的主要操作用它，最多两个并排：一个实色、一个描边。
- 页眉是吸顶的玻璃条，只放字标、几个链接和外观切换；图标按钮的点击区域是 `glass-button-size`（桌面 32、触屏 44），悬停底色比它小一圈。
- 文档页左侧可以有目录（`sidebar-width`），当前位置用 `fill-selected` 标出。窄于 `breakpoint-md` 时目录收起。

## 动效

品牌展示页可以有叙事动效（首页的麋鹿），但要能暂停、不妨碍阅读；减弱动态效果时保持静止。打字效果、滚动视差这类装饰只用一次，不要每个区块都动。

插画默认是黑白的。颜色只能作为用户触发、几秒后自行褪回黑白的插画效果出现（首页点鹿后场景上色）；页眉、文字、按钮和链接始终用黑白设计变量，不跟着变色。

## 不要

- 把这里的 44px 胶囊按钮和大字号搬进应用界面。
- 为了“高级感”加渐变、常驻的彩色插画或大面积阴影；让颜色进入页眉、文字和按钮。
- 把给 agent 或开发者看的安装说明放在首屏；放到页面末尾或单独的资源页。
